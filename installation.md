# Description

This is an executable mod built on top of Thinker mod. Thinker mod is bundled in. No need to install it separately.

This mod was tested on GOG SMAX version.

# Disclaimer

This is fan made mod that goes without warranty of any kind! Use it on your own risk. I recommend to install it to dedicated game directory and do not mix it with other mods.

# Installation

Take latest release package from here (TheWillToPower-###.zip) and unpack its content to game directory.

https://github.com/tnevolin/thinker-doer/releases

# Optional factions modifications

Look for "factions" release in release list.

Optional but recommended faction modifications. These are minimal changes required to match core rule changes.

Download faction release and unpack its content to game directory.

# Run

Run thinker.exe (preferred) or terranx_mod.exe. They both do the same thing. Although thinker.exe should be more modern and supporting resolution better.

# Windows scaling issue

If you experience scaling issues (game does not utilize full screen width with Windows scaling more than 100%), try setting DPI option.
Set them on terranx_mod.exe if you are using it. Set them on terranx.exe if you are using thinker.exe.

Right-click → Properties → Compatibility tab → Change high DPI settings → check "Override high DPI scaling behavior. Scaling performed by:" → set to Application → OK.
